# Design Kit

Portfolio design tokens and UI conventions.

## Colors

- Background: `#F2F2F2`
- Secondary background: `#EAE4D5`
- Foreground: `#000000`
- Accent: `#B6B09F`

## Typography

- Primary font: Cabinet Grotesk
- Large headings use tight letter spacing
- Body copy favors readable line height and muted foreground color

## Components

- Rounded cards with subtle borders
- Pill tags for technologies
- Dashed separators and decorative grid lines
- Light/dark theme variables
